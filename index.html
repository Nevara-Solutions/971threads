Issues

1

Footer typo: "New Arivals"

Medium Every page (footer)·Desktop + Mobile

The footer Quick Links label reads "New Arivals". It is missing an "r" and should be "New Arrivals". It is a hard coded label in the footer block, so it shows on every page of the site.

Fix: Edit the footer block link label to "New Arrivals" (Theme Editor footer block, or the link_2_2_text setting).

2

New Arrivals cards: size rows do not align

Low Home, New Arrivals slider·Desktop

When a product title wraps to two lines (for example "Camel Caravan Tee - Matcha Green"), the price and size chips are pushed down, so the S/M/L/XL rows no longer line up across the row. The images are equal height, but the text block below them is not reserved.

Fix: Give the card title a fixed min height (space for two lines) so price and size chips align across all cards.

3

"QUICK VIEW" bar always covers the image

Low Home, New Arrivals slider·Desktop

The dark "QUICK VIEW" bar is permanently visible across the bottom of each product photo and covers part of the image. If it is meant to appear on hover, it is currently showing at all times.

Fix: Reveal the Quick View bar on hover and focus only, or move it below the image so it does not cover the photo.

4

Search results cards are uneven height

Low Search results·Desktop + Mobile

On the search results page the product cards keep each image at its own ratio, so cards are different heights (for example the grey tee card is shorter than its neighbours). The equal height fix was applied to the collection grid but not to the search results grid, so the two look inconsistent.

Fix: Apply the same fixed 4:5 image ratio to the search results grid that the collection grid uses.

5

Mobile size chips run to the edge

Low Product page·Mobile

On mobile the size row (S, M, L, XL, 2XL) fills the full width with "2XL" pressed against the right edge. It fits today, but a sixth size or a longer label would overflow or wrap awkwardly.

Fix: Let the size chips wrap to a second row on narrow screens, or reduce the chip gap and padding on mobile.

6

FAQ mentions categories the brand does not sell

Low FAQ page·Desktop + Mobile

The FAQ says returns are not accepted on "underwear, socks, and innerwear". 971 Threads sells tees and hoodies only, so this reads like generic placeholder copy and can confuse customers.

Fix: Update the FAQ copy to reference the products you actually sell (tees and hoodies), or remove the line.

Working well

  • Every template renders cleanly: home, all collections, product pages, About, Contact, Cart, Search, 404, FAQ, and the policy pages.
  • Collection grid cards are uniform height (4:5) on desktop and mobile.
  • Footer payment badges are correct and clear on both desktop and mobile (Visa, Mastercard, Amex, Apple Pay).
  • Newsletter reads "Join the 971"; footer links, socials, and mobile accordions all work.
  • Product pages: size selector, Size Guide, quantity, and buy buttons are present and aligned.
  • Header, hero slideshow, and split collection sections are consistent across the site.
