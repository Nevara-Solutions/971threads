1

Footer typo: "New Arivals"

Medium All pages (footer)·Desktop + Mobile

The footer Quick Links show "New Arivals" — it is missing an "r" (should be "New Arrivals"). It is a hard-coded label in the AI footer block, so it appears on every page.

Fix: Edit the footer block link label (Theme Editor → footer block, or the link_2_2_text setting) to "New Arrivals".

2

New Arrivals cards: size rows don't align

Low Home — New Arrivals slider·Desktop

Product titles that wrap to two lines (e.g. "Camel Caravan Tee - Matcha Green") push the price and size chips down, so the S/M/L/XL rows no longer line up across the row. The images are equal height, but the text block below is not reserved.

Fix: Give the card title a fixed min-height (space for 2 lines) so price + size chips align across all cards.

3

"QUICK VIEW" bar always covers the image

Low Home — New Arrivals slider·Desktop

The dark "QUICK VIEW" bar is permanently visible across the bottom of each product photo, covering part of the image (model's legs). If it is meant to appear on hover, it is showing at all times.

Fix: Reveal the Quick View bar on hover/focus only, or move it out of the image so it doesn't cover the photo.

4

Mobile size chips run to the edge

Low Product page·Mobile

On mobile the size row (S · M · L · XL · 2XL) fills the full width with "2XL" pressed against the right edge. It fits for now, but a 6th size or a longer label would overflow / wrap awkwardly.

Fix: Allow the size chips to wrap to a second row on narrow screens, or reduce chip gap/padding on mobile.
